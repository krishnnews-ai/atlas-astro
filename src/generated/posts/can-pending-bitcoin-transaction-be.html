Can a Pending Bitcoin Transaction Be Cancelled?

Yes, a pending Bitcoin transaction may sometimes be replaced before it is confirmed, but calling it a simple “cancellation” can be misleading. Bitcoin does not have a central authority or cancel button that can simply pull a transaction back after it has been broadcast.

If a transaction is still unconfirmed in the Bitcoin mempool, the sender may be able to use Replace-by-Fee (RBF) to replace it with another transaction that spends the same inputs and pays a higher fee. Another technique, Child-Pays-for-Parent (CPFP), can help accelerate a stuck transaction, but it does not cancel the original payment.

Once a Bitcoin transaction has been confirmed in a block, the situation is different. A normal confirmed Bitcoin transaction cannot simply be cancelled or reversed.

The key distinction is between cancelling a transaction and replacing an unconfirmed transaction. Bitcoin's network does not process cancellations in the way a bank or payment app might.

Why Is a Bitcoin Transaction Pending?

When you send Bitcoin, the signed transaction is broadcast to the network. Before it is included in a block, it can remain in the mempool, where unconfirmed transactions wait for miners to select them for inclusion in a block.

A common reason for a transaction remaining pending is that its fee rate is too low compared with the fees being offered by other transactions competing for limited block space.

Network congestion can make the problem more noticeable. If demand for block space rises after you broadcast the transaction, a transaction with a relatively low fee rate may take longer to confirm.

Coinbase also lists insufficient fees, high network activity, network synchronization issues and insufficient confirmations among reasons a transaction can remain pending on its platform.

What Is Replace-by-Fee (RBF)?

Replace-by-Fee, or RBF, is the main mechanism people refer to when they ask whether a pending Bitcoin transaction can be cancelled.

Instead of literally cancelling the original transaction, RBF allows an unconfirmed transaction to be replaced by another transaction that spends at least one of the same inputs and pays a higher fee under the applicable replacement rules.

The new transaction can be constructed to send the Bitcoin to a different output, including an address controlled by the sender. If the replacement is accepted and later confirmed, the original conflicting transaction cannot also confirm using the same spent inputs.

Blockstream's current explanation describes RBF as a way to replace an unconfirmed Bitcoin transaction with a new version carrying a higher fee. Bitcoin Optech likewise describes RBF as a node policy for replacing an unconfirmed transaction with another transaction that spends at least one of the same inputs and pays a higher fee.

Can RBF Be Used to Cancel a Bitcoin Payment?

Sometimes, yes—but “replace” is the more accurate word.

Imagine you accidentally send 0.1 BTC to the wrong address. The transaction has been broadcast but is still unconfirmed.

If your wallet supports fee bumping and the transaction can be replaced, you may be able to create a replacement transaction that spends the same inputs and sends the funds to an address you control, while paying a higher fee.

If the replacement is accepted and confirmed, the original transaction will not subsequently confirm as a separate transaction using those same inputs.

However, this is not a guaranteed emergency cancellation feature. The exact options depend on the wallet, transaction structure and network policies.

What If My Wallet Shows “Bump Fee” or “Speed Up”?

Many modern Bitcoin wallets use terms such as “Bump Fee,” “Increase Fee,” or “Speed Up” for fee-management features.

These options are primarily designed to make an unconfirmed transaction more competitive for block inclusion. Depending on the wallet and transaction, the feature may use RBF or another fee-bumping mechanism.

If your goal is to stop an accidental payment rather than simply confirm it faster, do not assume that pressing “Speed Up” will cancel anything. Check exactly what the wallet is offering before signing a replacement transaction.

What Is CPFP and Does It Cancel a Bitcoin Transaction?

No. CPFP does not cancel a Bitcoin transaction.

CPFP stands for Child-Pays-for-Parent. It is primarily a way to encourage miners to confirm a stuck transaction by creating a second transaction with a higher fee.

The idea is relatively simple: a new “child” transaction spends an output from the unconfirmed “parent” transaction. Because the child depends on the parent, a miner that wants the child's fee generally needs to include the parent as well.

This can increase the effective fee rate of the package and make confirmation more attractive.

Mempool's documentation specifically identifies CPFP as an option when the sender cannot use RBF, provided the user controls an appropriate output from the stuck transaction.

So if you accidentally sent Bitcoin to the wrong address, CPFP is generally not the tool you want. It is designed to help get a transaction confirmed, not to undo it.

What Happens If the Bitcoin Transaction Is Already Confirmed?

This is where the answer becomes much simpler.

A normal Bitcoin transaction that has already been confirmed in a block cannot be cancelled through RBF.

RBF operates on unconfirmed transactions. Once the transaction has been included in a confirmed block, it is no longer sitting in the mempool waiting for inclusion.

That means an accidental payment to the wrong Bitcoin address generally cannot be recovered simply because the sender made a mistake.

At that point, recovery depends on the circumstances. If the recipient is known and willing to return the funds, they may send them back in a new transaction. If the destination belongs to an exchange or another identifiable service, contacting that service may be worth trying, although recovery is not guaranteed.

Can a Pending Transaction Eventually Disappear?

Yes, an unconfirmed transaction can eventually disappear from a node's mempool if it is not confirmed and is removed under that node's mempool policies.

That does not mean Bitcoin has processed a formal cancellation. It means the transaction is no longer being retained by that particular node or set of nodes.

Mempool notes that an unconfirmed transaction can either confirm or otherwise be removed from mempool handling, and users can continue tracking the transaction using its transaction ID.

If a transaction disappears from one mempool, that does not automatically mean the transaction has been cancelled everywhere. The safest approach is to check its status using a reputable Bitcoin block explorer and understand what your wallet is reporting.

What Should You Do If Your Bitcoin Transaction Is Stuck?

Before taking action, find the transaction ID, also known as the TXID, and check it on a Bitcoin block explorer.

Then determine whether it is:

  • Unconfirmed: It is still waiting for confirmation.
  • Confirmed: It has already been included in a block.
  • Missing from the mempool: It may have been dropped by the node or may require further investigation.

If it is unconfirmed, check whether your wallet provides an RBF or fee-bump option.

If you are trying to accelerate an incoming transaction and control an output that can be spent before confirmation, CPFP may be an option.

If the transaction was sent through an exchange rather than directly from a self-custody wallet, the exchange's own policies matter. Coinbase, for example, advises users with pending sends to check the transaction through a block explorer and contact support if the confirmation remains stuck.

What If You Sent Bitcoin to the Wrong Address?

This is one of the most important situations to understand.

If the transaction is still unconfirmed, you may have an opportunity to replace it depending on the transaction and wallet.

If it has already confirmed, however, Bitcoin itself cannot identify that you made a mistake and automatically return the coins.

If the address belongs to another person, the recipient would generally need to cooperate and send the Bitcoin back.

If the address belongs to an exchange or identifiable service, contact its official support channel as soon as possible and provide the TXID and relevant transaction information.

Never give anyone your seed phrase or private keys while asking for help recovering a transaction.

Does RBF Guarantee That a Transaction Can Be Cancelled?

No.

RBF is a transaction replacement mechanism, not a guaranteed cancellation service.

There are technical rules governing replacements, and wallet interfaces vary. A replacement transaction also needs to be accepted and propagated through the network before it can compete for confirmation.

Most importantly, once a conflicting transaction has already been confirmed, the opportunity to replace the original unconfirmed transaction is gone.

Can Coinbase or Another Exchange Cancel a Pending Bitcoin Transaction?

This depends on what “pending” means inside the exchange.

An exchange may have an internal status for a withdrawal that has not yet been broadcast to the Bitcoin network. In that situation, the exchange may have more control than it would after the transaction has been broadcast.

Once an actual Bitcoin transaction has been broadcast to the network, however, the exchange cannot simply rewrite Bitcoin's blockchain history.

Coinbase distinguishes between pending transactions and confirmed transactions and notes that once a blockchain transaction is confirmed, it cannot be reversed.

Bottom Line

Can a pending Bitcoin transaction be cancelled? Not in the traditional sense.

If the transaction is still unconfirmed, RBF may allow you to replace it with another transaction, potentially redirecting the funds while paying a higher fee. CPFP can help accelerate confirmation but does not cancel the original transaction.

Once a transaction has been confirmed, there is no normal Bitcoin “undo” button. Recovery then depends on the recipient, exchange or other party involved—not on reversing the confirmed Bitcoin transaction itself.

The safest habit is simple: check the address and amount carefully before signing and broadcasting a Bitcoin transaction.

Frequently Asked Questions

1. Can I cancel a Bitcoin transaction while it is pending?

Sometimes. If it is still unconfirmed, an appropriate RBF replacement may allow the original transaction to be replaced. Bitcoin does not provide a conventional cancel button.

2. Can I cancel a Bitcoin transaction after one confirmation?

No. Once a normal transaction has been confirmed in a block, RBF cannot be used to replace it.

3. What is RBF in Bitcoin?

RBF, or Replace-by-Fee, is a mechanism that allows an unconfirmed transaction to be replaced with another transaction that satisfies the network's replacement rules and pays a higher fee.

4. Does CPFP cancel a stuck Bitcoin transaction?

No. CPFP, or Child-Pays-for-Parent, is designed to encourage confirmation of an unconfirmed transaction by attaching a higher-fee child transaction.

5. Why is my Bitcoin transaction stuck pending?

A transaction can remain pending because of a relatively low fee rate, network congestion, node synchronization issues or other transaction-processing conditions.

6. What happens if my Bitcoin transaction never confirms?

An unconfirmed transaction may eventually be removed from a node's mempool under its policies. If that happens and the transaction is no longer being propagated, the underlying coins may become available to spend again, depending on the wallet and transaction state.

7. Can an exchange reverse a Bitcoin transaction?

An exchange may be able to cancel an internal or not-yet-broadcast withdrawal under its own systems. Once a Bitcoin transaction has been broadcast and confirmed on the blockchain, however, the exchange cannot simply reverse the confirmed transaction.
