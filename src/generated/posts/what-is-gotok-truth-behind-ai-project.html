1. GETok — The AI Research Project

What Is GETok?

GETok is a spatial representation method introduced in a research paper titled “Grounding Everything in Tokens for Multimodal Large Language Models.”

The paper was first submitted to arXiv in December 2025 and was subsequently published in the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR) 2026.

The research explores how multimodal large language models can represent spatial information more effectively using specialized tokens.

In simple terms, GETok is designed to help AI systems become better at understanding where objects are located inside an image, rather than simply identifying what objects appear in the image.

What Problem Is GETok Trying to Solve?

Modern multimodal AI systems can process text and images, but precise visual localization remains a difficult problem.

An AI model may correctly identify a car, pedestrian or traffic sign in a photograph. A more difficult task is determining the precise location of that object and representing that location consistently.

GETok approaches this problem by introducing a specialized vocabulary of learnable spatial tokens into multimodal language models.

How Does GETok Work?

One simple way to understand the approach is to imagine placing a grid over an image.

GETok uses grid tokens to represent structured locations in the image and offset tokens to refine those locations.

This creates a coarse-to-fine approach to spatial localization. The model first identifies a general area and can then refine the position through additional spatial information.

According to the research, the framework can represent different types of spatial information, including points, bounding boxes, masks and polylines.

The important distinction is that these are AI representation tokens. They are not blockchain tokens or tradable cryptocurrency assets.

Is GETok an AI Cryptocurrency?

The official GETok research sources reviewed describe it as an AI research method, not as a cryptocurrency.

This distinction matters because the word “token” has different meanings in technology.

In artificial intelligence, a token can represent a unit of text, visual information or another learned representation. In GETok, tokens are used to represent spatial information.

In cryptocurrency, a token normally refers to a blockchain-based digital asset.

Therefore, seeing the word “token” in an AI research paper does not mean that the project has a tradable cryptocurrency.

2. gotok — The Developer Token-Counting Tool

A completely separate open-source project named gotok is a developer utility written in Go.

Its purpose is to help developers count tokens in text using tokenization standards associated with language models.

Token counting can be useful when building AI applications because developers may need to estimate prompt size, understand context usage or calculate approximate API-processing requirements.

The project documentation identifies support for multiple token encodings used by different language-model systems.

This gotok project is developer software rather than a cryptocurrency.

Most importantly, there is no basis for assuming that this developer utility is the same project as GETok simply because both names contain “tok.”
