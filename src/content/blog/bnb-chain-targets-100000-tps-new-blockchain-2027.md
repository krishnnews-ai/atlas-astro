BNB Chain is preparing a new Layer 1 blockchain designed for high-speed trading, automated payments and AI-driven transactions, with a mainnet launch targeted for early 2027. The proposed network, provisionally known as New L1, aims to process more than 100,000 transactions per second while keeping BNB as its native token.

The project is expected to operate alongside BNB Smart Chain rather than replace it. According to the roadmap and technical information reported in October, BNB Chain is targeting a public testnet before the end of 2026, giving developers an opportunity to assess its performance before a wider launch.

The ambitious targets could strengthen BNB Chain's position in the race to build faster blockchain infrastructure. However, the proposed throughput and confirmation times still need to be demonstrated under public testing and real-world conditions.

## Why Is BNB Chain Building Another Blockchain?

BNB Chain already supports decentralised finance, token transfers, trading applications and other blockchain services through its existing infrastructure. Its proposed New L1 network is intended to address workloads where transaction speed and predictable execution are particularly important.

These include high-frequency crypto trading, on-chain order books, automated payments and financial applications operated by software agents.

Such applications can be sensitive to delays. A trading strategy that depends on rapid execution, for example, may become less effective if transactions wait too long to be processed or network congestion increases costs.

Rather than forcing every application onto one network, BNB Chain is pursuing a multi-chain approach. The new blockchain would offer a separate environment for demanding workloads while BNB Smart Chain continues to support its existing applications and users.

The idea is not entirely new in the blockchain industry. Different networks often specialise in particular workloads, but the challenge is ensuring that additional infrastructure creates genuine utility rather than splitting liquidity and developer activity across disconnected ecosystems.

## New L1's Performance Targets Explained

BNB Chain's proposed technical targets are ambitious. The network aims to deliver more than 100,000 transactions per second, block production at approximately 200-millisecond intervals and transaction pre-confirmations in around 20 milliseconds.

These figures describe development objectives, not independently verified mainnet performance.

A transaction pre-confirmation is also different from final settlement. A pre-confirmation can provide an early indication that a transaction is expected to be included, but it does not necessarily mean that the transaction has been executed and irreversibly finalised.

That distinction matters for trading platforms, lending protocols and applications handling liquidations. Developers will need to evaluate how the system behaves when validators experience delays, transaction demand spikes or network conditions deteriorate.

The proposed architecture includes an upgraded version of Parlia, the consensus mechanism used by BNB Chain, alongside changes intended to improve coordination and transaction execution. Technical documents also describe a validator configuration targeting up to 64 validators.

Whether these design choices can deliver the promised performance while maintaining sufficient decentralisation will become clearer as testing progresses.

## BNB Will Remain the Network's Native Token

One notable feature of the plan is the intention to use BNB across the broader ecosystem instead of introducing a separate token for New L1.

BNB is expected to remain the native asset for transaction fees, staking and governance. On October 25, Binance founder Changpeng Zhao, widely known as CZ, expressed support for the approach on X using the phrase "Multiple chains, one coin."

A shared token model could make the relationship between BNB Smart Chain and the new network easier to understand. It also avoids immediately creating another token economy with its own supply, distribution and incentive structure.

However, a decision to retain BNB does not automatically mean its market price will rise.

The effect on BNB's economic activity will depend on how the new network is implemented, the fees it generates, the applications it attracts and whether users choose to conduct meaningful activity on it. A successful launch could increase demand for network services, but technical development alone does not guarantee additional token demand.

## Trading, DeFi and AI Agents Are Key Use Cases

New L1 is being developed with applications requiring rapid transaction processing in mind. High-speed trading is one potential use case, particularly for decentralised exchanges and on-chain order-book systems.

The network's planned architecture also includes mechanisms intended to allocate capacity to selected types of operations, including DeFi liquidations, oracle activity and cross-chain transfers.

This approach could help prevent a surge in one category of transactions from consuming all available network capacity. The practical results, however, will depend on how these mechanisms work under heavy demand.

AI agents are another intended use case.

An AI agent is software that can perform tasks automatically, potentially including checking data, interacting with smart contracts and initiating transactions within predefined permissions. If these systems become more widely used in financial applications, they could generate frequent, automated transactions.

BNB Chain is exploring features such as sponsored transaction fees, temporary key permissions and transaction batching to support these workflows. Such features could make it easier for developers to build applications in which software performs multiple blockchain operations without requiring a user to approve every individual step manually.

The opportunity is still developing. The existence of an AI-focused infrastructure does not itself establish demand; developers will need to build useful products that attract active users.

## Could the New Network Reduce Front-Running?

Transaction ordering is an important issue for decentralised finance.

On many public blockchains, pending transactions can be visible before they are included in a block. Traders and automated bots may analyse that information and attempt to place transactions before or after another user's order to capture a price advantage.

BNB Chain's plans include changes to transaction delivery intended to reduce opportunities for certain forms of front-running. Its broader technical direction also involves handling transactions in ways designed to improve execution speed and limit congestion.

These measures could make some attacks more difficult, but they should not be interpreted as eliminating every form of transaction-ordering manipulation or maximum extractable value, commonly known as MEV.

The final assessment will depend on implementation details, validator behaviour, transaction visibility and the safeguards available to users. Public testing will be important in determining whether the proposed protections work as intended.

## What Happens Before the 2027 Launch?

BNB Chain is targeting a public testnet in late 2026, followed by a potential mainnet launch in early 2027. Development has already progressed to a private testing environment, according to recent reporting, but the public network is not yet generally available.

Several questions remain open.

First, independent testing will need to establish whether the network can sustain high transaction throughput without sacrificing reliability. Advertised maximum capacity is not the same as consistent performance under real market conditions.

Second, the validator structure will deserve attention. The number of validators, their independence, hardware requirements and distribution of staking influence can all affect the network's resilience and decentralisation.

Third, the proposed bridge between BNB Smart Chain and New L1 will need to demonstrate strong security. Cross-chain bridges can introduce risks when assets or messages move between separate networks, making careful design and auditing essential.

Finally, the project will need applications and users. Fast block production can be attractive to developers, but lasting adoption depends on security, liquidity, reliable infrastructure and products that solve real problems.

The roadmap could change as development continues, so the planned dates should be treated as targets rather than guaranteed deadlines.

## What the New Blockchain Could Mean for BNB Chain

BNB Chain's proposed New L1 represents a push to expand beyond general-purpose blockchain activity into faster trading, automated financial operations and AI-assisted transactions.

Keeping BNB as the common token could help maintain continuity across the ecosystem, while a separate execution environment could give developers more options for applications that need low latency.

Still, the most important milestones have yet to be demonstrated publicly. The 100,000-transactions-per-second target, rapid pre-confirmations, validator design and cross-chain infrastructure will need to be tested before users can judge the network's real capabilities.

For now, the project is best understood as a planned expansion of BNB Chain's infrastructure—not a replacement for BNB Smart Chain, a confirmed guarantee of higher BNB prices or proof that the advertised performance has already been achieved.

The public testnet will be the next major opportunity to assess whether the design can translate into a reliable blockchain for trading, DeFi and AI-powered applications.
